# NeawStreamTV 📺

Un reproductor multimedia nativo y optimizado para **Android TV**, **Google TV** y **Fire TV Stick**, desarrollado en **Kotlin** utilizando el motor de renderizado **ExoPlayer (Media3)**.

Este proyecto ha sido diseñado como una herramienta de software libre, de código abierto y completamente neutra para la reproducción de flujos de video y listas multimedia en formato HLS (`.m3u8`) y Xtream.

## 🛠️ Características Técnicas

* **Lenguaje:** 100% Kotlin optimizado para entornos embebidos y televisores.
* **Motor de Video:** AndroidX Media3 / ExoPlayer estándar (sin dependencias binarias propietarias).
* **Compatibilidad de Red:** Integración con OkHttpDataSource para un streaming HTTP/HLS fluido y seguro.
* **Interfaz de TV:** Diseñado para una navegación cómoda utilizando exclusivamente el control remoto (D-Pad).
* **Privacidad:** Libre de rastreadores, analíticas intrusivas de terceros y librerías cerradas de Google Mobile Services (GMS)

## 📦 Instalación

Al ser un proyecto de código abierto enfocado en la privacidad del ecosistema, puedes instalar la aplicación de dos formas:

1. **Compilación Propia:** Clona este repositorio en Android Studio y genera tu propia APK firmada de manera local.
2. **Descarga Directa:** Ve a la sección de **Releases** en este repositorio y descarga el archivo `.apk` más reciente para instalarlo directamente en tu dispositivo de TV.
